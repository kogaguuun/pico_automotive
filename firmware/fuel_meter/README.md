# fuel_meter — 燃料（ガソリン）メーター

燃料レベルセンサのADC値を、I2C OLEDにゲージ表示するスケッチ群。
組み込み別編シリーズ第1話の題材。

## ハードウェア

- ディスプレイ: SSD1306 128x64 OLED（I2C、SCL=GP5 / SDA=GP4）
- センサ入力: GP26（ADC0）
- ライブラリ: U8g2

## スケッチ

| フォルダ | 内容 |
|---|---|
| `gas/` | オリジナル版（Koga作）。円形ゲージ＋中央にポンプアイコン。ポンプアイコンはビットマップではなく図形プリミティブ（Box/Line）で描かれている |
| `gas_ui1/` | UI案1「大きい数字＋バー」版。センサ読み取りとポンプアイコン描画は `gas/` からそのまま流用し、表示を大きい残量数字＋バーゲージ＋12セグメントに変更。レイアウトは `ui-mockups/ui1_native_icon.png` の実測値ベース |

## メモ

- パーセント換算 `map(raw, 0, 1023, 0, 100)` の範囲は仮置き。実センサに合わせてキャリブレーションする。
- 将来の表示先候補: SSD1327 128x128 グレースケール（SPI）への移植を想定。
